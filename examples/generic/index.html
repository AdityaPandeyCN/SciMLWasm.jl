SciMLWasm

Write a system of ODEs, solve it in WebAssembly. No server, nothing recompiles.

Equations

Syntax

One equation per line, dx = … or x' = …. The left side names a state; states are ordered as written.
Any other name on the right is a parameter and gets a slider. t is time. Numbers may use 1e-3. # starts a comment.
Operators + - * / ^ (^ is right-associative, ** also works). Functions: sin cos tan exp log sqrt abs tanh sinh cosh atan min max. Constants pi, e. Up to 8 states.

Initial state and time

Parameters

None yet. Names on the right-hand side that are not states become parameters.

Solver

Solves as you type. Ctrl+Enter solves now.

The page parses the equations to bytecode for a small stack machine inside a single WebAssembly module that also carries both integrators, so any system solves without recompiling. Rosenbrock23 forms a finite-difference Jacobian and factors a matrix every step, which is what keeps it stable on stiff problems where the explicit method needs unusably small steps.
